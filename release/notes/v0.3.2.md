## Apache 2.0 Release

Grengin v0.3.2 is the first public product release licensed under the Apache
License 2.0. It contains the Grengin frontend and a pinned Grengin API revision
as source archives and static Linux AMD64/ARM64 bundles.

Releases v0.3.1 and earlier remain governed by the license included in their
archives and are retained as archived legacy releases.
