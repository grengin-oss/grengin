## Grengin v0.9.8

Complete frontend and backend source archives, plus static Linux AMD64 and ARM64 bundles.
The backend is Grengin API v0.9.8, pinned to commit `1d6c534d8d7b76f06705478f0691eaaef640cfef` and its published image digest.

Install the latest stable Linux release:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://meta.grengin.com/install.sh | sh
```

Backend container:

```bash
docker pull ghcr.io/grengin-oss/grengin-api:v0.9.8
```
