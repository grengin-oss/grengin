## Grengin v0.9.4

Complete frontend and backend source archives, plus static Linux AMD64 and ARM64 bundles.
The backend is Grengin API v0.9.4, pinned to commit `804f09a348e81ae184f8fd0647c84ce3f3060242` and its published image digest.

Install the latest stable Linux release:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://meta.grengin.com/install.sh | sh
```

Backend container:

```bash
docker pull ghcr.io/grengin-oss/grengin-api:v0.9.4
```
