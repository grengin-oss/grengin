## Grengin v0.9.3

This release contains the Grengin frontend and the exact Grengin API v0.9.3
source revision as complete source archives and static Linux AMD64/ARM64
bundles.

Install the latest stable Linux release with:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://meta.grengin.com/install.sh | sh
```

The backend container is available for Linux AMD64 and ARM64:

```bash
docker pull ghcr.io/grengin-oss/grengin-api:v0.9.3
```
