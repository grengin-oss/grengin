## Grengin v0.9.6

- Inline composer command menus, suggestions and keyboard shortcuts.
- Dynamic AI-provider categories and improved provider filtering.
- Backend discovery accepts inline categories and retains the category-sidecar
  fallback.
- A dedicated 0.9.6 compatibility catalog retains the tested 18 AI providers
  and 7 auth templates without changing existing package hashes.

Includes complete frontend/backend source ZIP and TAR archives, Linux AMD64/ARM64
bundles and SHA-256 checksums. The backend source is pinned to
`b365aca6699cefbef95c74dc49dd57b16e49e6ab`; exact component commits and versions
are recorded in each archive's `RELEASE-MANIFEST.json`.

```bash
curl --proto '=https' --tlsv1.2 -sSf https://meta.grengin.com/install.sh | sh
```

```bash
docker pull ghcr.io/grengin-oss/grengin-api:v0.9.6
```

There is no new backend database migration relative to 0.9.5. Back up your database
before upgrading. This release targets single-instance operation; SSE transport
is unchanged. The experimental connector OAuth broker is not included.

Known limitations: existing dependency advisories and the unversioned
provider-runtime reload path are not resolved by this release. Frontend checks
pass with existing Svelte warnings and bundle-size warnings; this is not a
warning-free or bug-free release claim.
