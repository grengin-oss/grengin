## Grengin v0.9.14

Complete frontend and backend source archives, plus Linux AMD64 and ARM64 bundles.
For 0.9.13 and newer, native bundles require glibc 2.36 or newer and libgcc_s.so.1; use the container on incompatible systems.
The backend is Grengin API v0.9.14, pinned to commit `8666b796c9b8ef73e6921193660940c04e430c4d` and its published image digest.

Install the latest stable Linux release:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://meta.grengin.com/install.sh | sh
```

Backend container:

```bash
docker pull ghcr.io/grengin-oss/grengin-api:v0.9.14
```
