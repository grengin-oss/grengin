## Grengin v0.9.5

- Security fixes for authorization, role/department changes, audit persistence,
  files, chat edits and MCP OAuth.
- Backend organization/department chat sharing, private copies and eligible-user
  notifications. Sharing endpoints are documented in Swagger.
- AI providers are discovered without inserting every suggestion into the database.
  Connecting a new provider installs that provider only; the first key enables it
  with bounded defaults while preserving existing restrictive allowlists.
- Provider browsing works on a fresh installation without pre-seeded engine rows.

Includes complete frontend/backend source ZIP and TAR archives, Linux AMD64/ARM64
bundles and SHA-256 checksums. Exact source commits are in RELEASE-MANIFEST.json.

```bash
curl --proto '=https' --tlsv1.2 -sSf https://meta.grengin.com/install.sh | sh
```

Known issues: the backend dependency advisory scan still reports existing findings,
and runtime provider reloads retain an unversioned manifest path. This release does
not claim to resolve those findings. Back up the database before upgrading; the
share migration's rollback deletes shares and their notifications. Single-instance
operation only; SSE transport is unchanged.
