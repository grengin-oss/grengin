## Grengin v0.9.13

Complete frontend and backend source archives, plus static Linux AMD64 and ARM64 bundles.
The backend is Grengin API v0.9.13, pinned to commit `e9bcb2a02e86fd65c236f9ed4c53dbd5cd55b603` and its published image digest.

Install the latest stable Linux release:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://meta.grengin.com/install.sh | sh
```

Backend container:

```bash
docker pull ghcr.io/grengin-oss/grengin-api:v0.9.13
```
