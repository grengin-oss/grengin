## Grengin v0.9.13

Complete frontend and backend source archives, plus Linux AMD64 and ARM64 bundles.
The backend is Grengin API v0.9.13, pinned to commit `e9bcb2a02e86fd65c236f9ed4c53dbd5cd55b603` and its published image digest.

### Native runtime requirements

The backend now uses glibc instead of static musl. Native bundles require glibc
2.36 or newer, `libgcc_s.so.1` and a CA certificate store, such as Debian 12.
Alpine/musl hosts should use the container instead. Bundles include
`grengin-migrate` for explicit database migrations. The retired `sqlx-mcp`
binary is no longer shipped; do not re-enable its old stdio server entry.

### Scope

This release includes the backend and frontend already merged for 0.9.13.
Pending security/runtime PRs and their combined validation are being prepared
for 0.9.14. The Grengin provider integration does not establish that the hosted
proxy service has been deployed or configured successfully.

Install the latest stable Linux release:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://meta.grengin.com/install.sh | sh
```

Backend container:

```bash
docker pull ghcr.io/grengin-oss/grengin-api:v0.9.13
```
