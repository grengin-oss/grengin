# Contributing

Grengin is built by the team at Perter Technology Solutions. The
repositories are public so you can read the code, run it, audit it, and
fork it. All four are welcome.

## Issues

Bug reports and feature requests are the most useful thing you can send
us. Open an issue with the version you are running, what you expected,
and what happened instead.

## Pull requests

Development happens in-house, so we cannot promise every external pull
request gets merged, and larger changes are worth raising as an issue
first so nobody wastes an afternoon. Small fixes are genuinely welcome.

There is nothing to sign. Under Section 5 of the Apache License 2.0,
anything you deliberately submit for inclusion is offered under the same
license as the project, unless you say otherwise in the submission.
